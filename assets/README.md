# Брендовые файлы (необязательно)

Основной файл оформления:

- `poster-template.png` — постоянная фирменная афиша без даты. Бот не меняет композицию и каждую неделю наносит только новый диапазон дат.

Дополнительные старые варианты ниже больше не используются основным шаблоном, но могут храниться как исходники:

- `background.jpg` — квадратный или горизонтальный фон Мариуполя, желательно не меньше 1080×1080;
- `logo.png` — логотип GoМарик на прозрачном фоне.

Не удаляйте `poster-template.png`: без него бот намеренно отменит публикацию, чтобы в канал не попала обложка другого стиля.
