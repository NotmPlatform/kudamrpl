# Брендовые файлы (необязательно)

Чтобы обложка была максимально близка к текущему оформлению канала, положите сюда:

- `background.jpg` — квадратный или горизонтальный фон Мариуполя, желательно не меньше 1080×1080;
- `logo.png` — логотип GoМарик на прозрачном фоне.

Если файлов нет, бот использует встроенный тёмно-синий/оранжевый шаблон. Если файлы есть, фон автоматически затемняется для читаемости, а логотип помещается сверху.
